# Мария & Максим — 01.11.2026

Свадебный сайт-приглашение: scroll-driven 3D-сцена с фарфоровой маской, рисунок
из точек и линий на обратной стороне, отсчёт до 1 ноября 2026 года и ленивая
карта в модалке.

## Стек

- Vite + vanilla JS (ES modules)
- Three.js, GSAP + ScrollTrigger, Lenis
- Leaflet (ленивый импорт только при открытии карты)
- Шрифты self-hosted: Cormorant Garamond и IBM Plex Mono через `@fontsource`
- Деплой: GitHub Actions → GitHub Pages

## Команды

```powershell
npm install
npm run dev       # http://localhost:5173/wed-site/
npm run build     # production-сборка в dist/
npm run preview   # предпросмотр production-сборки
```

Production-сайт собирается под base path `/wed-site/`.

### Пересборка маски

Исходник `pigeon_mask_v2.obj` (98 МБ) лежит в `assets/source/` и не попадает в
git. Если Blender не в `PATH`:

```powershell
& "C:\Program Files\Blender Foundation\Blender 5.2\blender.exe" `
  --background --factory-startup --python scripts/build_mask.py
```

Скрипт:

1. импортирует OBJ и применяет трансформации;
2. сваривает дубли, пересчитывает нормали;
3. делает decimate до ~300 000 треугольников (полигонаж выше исходного плана,
   чтобы гравировка не превращалась в треугольные шипы);
4. центрирует и масштабирует модель;
5. экспортирует `public/models/mask.glb` с Draco;
6. рендерит контрольные ракурсы в `scripts/renders/`.

Результат — GLB около 0,69 МБ. Draco-декодер лежит локально в `public/draco/`,
внешних CDN в рантайме нет.

### Запечка рисунка по гравировке

```powershell
# нужен запущенный npm run dev
node scripts/bake-engraving.mjs
```

Скрипт ставит сцену в финальный ракурс, замораживает маску, снимает блики
рельефа и сохраняет точки на поверхности в `src/text/engraving-points.js`.
Благодаря этому созвездие рисуется ровно по существующей гравировке, а не по
отдельной текстовой сетке и не «плывёт» относительно букв.

### Контрольные изображения

```powershell
node scripts/make-images.mjs
```

Скрипт собирает `mask-fallback.webp`, `mask-fallback-mobile.webp` и
`og-image.png` из подготовленных скриншотов в `scripts/renders/`.

## Структура

```
src/
  config.js              дата, имена, локации, строки приглашения
  main.js                запуск сцены, Lenis + ScrollTrigger, UI
  scene/                 renderer, маска, материалы, окружение, фон
  text/                  точки по гравировке, линии, созвездие
  scroll/                Lenis и scrub-таймлайн
  ui/                    отсчёт, reveal, карта-модалка
  styles/                палитра, сцена, нижняя галерея, модалка
scripts/
  build_mask.py          Blender headless: OBJ → GLB
  bake-engraving.mjs     снимок рельефа → local-space точки
  inspect_mask.py        отладочные ракурсы
  make-images.mjs        webp/og-изображения
```

## Сценарий

- `p 0.00–0.12` — маска лицевой стороной, имена и дата.
- `p 0.12–0.55` — маска поворачивается к зрителю обратной стороной.
- `p 0.55–0.80` — камера подъезжает к гравировке; в углублении проявляются
  точки и линии, складывающиеся в буквы.
- `p 0.80–1.00` — сцена мягко уходит в матовую бумагу; ниже начинается обычная
  HTML-галерея.

На маске нет отдельной текстовой плоскости или HTML-копии: буквы — это
физическая гравировка модели, поверх которой проявляется созвездие из точек и
линий, запечённых по этой же гравировке. Поэтому рисунок ложится ровно на
рельеф, а не образует второй шрифт. Полный читаемый дубль приглашения находится
в нижнем блоке, там же работают ссылки на карты.

## Детали

- Координаты: ЗАГС №1 — `55.765975, 37.644818`; особняк Василия Хлудова —
  `55.769884, 37.659668`.
- Карта: OpenStreetMap-тайлы, приведённые CSS-фильтром к светлой палитре.
  CARTO Positron сейчас требует ключ, поэтому от него отказались; Leaflet
  загружается только при открытии модалки.
- Отсчёт считает до абсолютного времени `2026-11-01T15:00:00+03:00`. Если время
  прошло, вместо цифр показывается «Это случилось».
- При `prefers-reduced-motion` отключаются покачивание, параллакс и побуквенный
  stagger; остаётся мягкое появление.
- Без WebGL показывается статичная картинка маски (desktop/portrait), нижний
  блок остаётся рабочим.
- DPR ограничен 2, адаптивно снижается при просадке fps; рендер ставится на
  паузу, когда вкладка скрыта или сцена вне вьюпорта.

## Деплой

на `https://bovam.github.io/wed-site/`.

## Проверено

- 390×844 и 360×800: нет горизонтального скролла, маска и нижний блок читаемы.
- 1440×900: сцена, hero, отсчёт, карточка приглашения и подвал.
- Гравировка читается в финальном ракурсе; точки/линии совпадают с рельефом.
- Обе локации открывают модалку с нужным маркером и ссылкой на Яндекс.Карты;
  закрытие по кнопке, Escape и клику по фону.
- Production-сборка под `/wed-site/` (Vite preview): модель, шрифты и Draco
  грузятся локально, ошибок в консоли нет.
- Fallback без WebGL.
- Локальный production-FCP ≈ 0,5 с. Lighthouse в headless-окружении без
  аппаратного WebGL компилирует шейдеры через SwiftShader, поэтому его TBT и
  итоговая оценка не показательны для реального телефона.

## Упрощения

- Вместо CARTO Positron — OSM-тайлы с CSS-фильтром (без ключей).
- В сцене нет кликабельных строк и текстовой плоскости: только гравировка и
  рисованное созвездие; читаемый дубль и ссылки — в нижнем блоке.
- Текст на маске в модели v2 уже присутствует в виде рельефа, поэтому он
  используется как основа, а не накладывается текстурой.
- Полигонаж маски поднят до ~300k, чтобы рельеф гравировки оставался гладким и
  читаемым; GLB при этом — 0,69 МБ, в лимит 1,5 МБ укладывается.
